配置与操作边界¶

运行环境¶

项目主运行环境是Linux、Python3.11+、uv和本机PostgreSQL16。WSL是停止的回滚副本。实际主机/账号信息见私有交接文档；公开站不列真实连接目标。依赖以锁文件为准，不自行升级。

普通配置在config.yaml；API keys和数据库凭据只在.env。本站仅说明配置键的用途，不读取/复制真实.env、数据库连接串、备份或私有报告。

配置领域 负责什么 来源
chains / sources / routing 支持链、来源与路由优先级 公开配置
HTTP / 限流 / 额度 请求重试与免费额度约束 配置模型
labels / holders / retention 标签策略、持仓目标与快照保留 同上，具体默认值以源码/公开配置为准
DATABASE_URL / 来源key 连接与认证，不能写入Git/日志/Fixture/数据库 .env本地管理，不在网站显示值

不要顺手执行的操作¶

db upgrade、初始化SQL、db prune、同步、probe、worker、live/e2e、批量导入/回填、正式数据更正及外部高成本请求都要先核对授权、目标库和请求范围。标签写入/任务入队也不是只读操作。

M3正式0006与内部研究导入已在2026-10-28完成；不因旧文档写着“待执行”再次导入或恢复claim。成功质量check只复用既有SHA证据，不重跑。直接SQL不遵循应用身份/标签锁，不能作为并发写入替代入口。

M3当前用途限内部研究，未知日期/issuer与BSL1.1/来源许可保持；公开技术说明不等于授予对外发布业务数据或第三方API权限。

常见排查顺序¶

先读已有状态/失败类型与具体任务，不盲目重试；缺证保留partial/unknown。查询只投影必要字段并加范围和LIMIT，不输出凭据。环境/权限异常和原生间歇崩溃不能因一次重试成功就宣称根因已修复。
