从这里开始¶

这是阅读型手册，不是数据库管理界面。网站打开、构建和搜索不会连接业务数据库，也不会替你执行示例。

先看已有数据¶

在项目根目录使用以下入口。999只是示例UCID，需换成库里已有的真实UCID；命令本身会连接已配置数据库。

uv run python -m aitrade --help
uv run python -m aitrade tokens stats
uv run python -m aitrade --json tokens show 999
uv run python -m aitrade --json holders show 999
uv run python -m aitrade jobs list --limit 20

上述stats/show/list读取已有结果；不是重新同步或采集。全局--json放在子命令之前。持仓和部分标签命令本来就返回JSON，详见接口说明。tokens resolve则可能在本地未命中时请求CMC，不能一概当作离线查询。

先选一个问题¶

  • 找UCID、合约、部署者：代币与UCID。
  • 看最新持仓、时间与快照差异：持仓快照。
  • 理解来源优先级、人工标签、排除结论：地址标签。
  • 理解队列状态、failed/partial和额度：任务与状态。
  • 想直接查数据库：只读SQL，从限定UCID和LIMIT开始。

操作分级¶

类型 例子 需要知道什么
查看已有业务数据 tokens show/stats/conflicts、holders show/diff、labels show、jobs list、status 连接数据库读取，不触发采集
条件联网/可选写入 tokens resolve 本地未命中才问CMC；联网可能产生额度记账，--add还登记手动合约
业务写入/入队 labels add/import、jobs enqueue/retry、labels heuristic默认模式 改标签或队列；不是只读查看
采集与运行 tokens sync、probe、jobs run 外部请求、免费额度与写入风险，必须先确认具体范围
正式迁移/清理/导入 db upgrade、db prune、离线import脚本 需单独授权；不得按教程顺手执行

标签启发式必须显式加--dry-run才不保存。不要因某个命令名字含show、resolve或check就猜其副作用；完整条目见命令参考。

配置前提¶

Python 3.11+、uv、本机PostgreSQL 16。按锁文件安装；凭据只在.env中，本站不展示任何真实配置值。配置细节和授权边界见运维说明。
