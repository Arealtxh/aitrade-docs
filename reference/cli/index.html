CLI 完整参考¶

参数/别名/默认值从当前CLI源码自动提取；用途与副作用由人工核对。自动参考不运行命令。

全局选项¶

全局选项放在子命令之前；--help由Typer提供。

参数/选项 类型 默认 源码帮助/约束
--config Path Path('config.yaml') 配置文件路径
--log-level str 'info' debug | info | warning
--json bool False 机器可读输出
--version bool False 显示版本

db upgrade¶

执行显式Alembic升级；--sql仅输出SQL。

副作用： 默认写目标库结构，必须单独授权；--sql不执行SQL但仍需有效配置。

返回内容： 迁移日志；非--sql成功时JSON包含command/revision/status。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
revision str 'head' 目标版本，默认 head
--sql bool False 只打印 SQL，不执行

status¶

查看队列汇总、错误和额度快照。

副作用： 读取数据库，不调用来源。

返回内容： jobs、top_errors、quota或终端表格。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--kind str \| None None 只看某个 kind

probe¶

显式探测来源能力，生成探针报告。

副作用： 外部请求/额度与本地报告写入；需确认范围，不是只读业务查看。

返回内容： 探针状态、报告路径；阻断项可返回4。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--source str \| None None 只跑某个数据源相关的探针（P1 编号或名称）
--out Path \| None None 报告输出路径，默认 reports/probe-.md

jobs enqueue¶

为deployer/holders/address_profile登记任务。

副作用： 写队列；--force重置可重跑任务，--with-funding扩大画像内容。

返回内容： kind/chain/ucids/enqueued/force。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--kind str 必填 deployer | holders | address_profile
--chain str \| None None 只选这条链
--ucid list[int] \| None None 只选这些 UCID，可重复；min=1
--force bool False 重置非 running 任务并重新解析
--with-funding bool False address_profile额外查询首笔资金

jobs run¶

启动worker处理已有任务。

副作用： 默认持续运行，可能联网、消耗额度、写业务及队列；须授权。

返回内容： worker/claimed/done/partial/requeued/failed/reaped/by_kind。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--kind list[str] \| None None 只跑这些 kind，可重复
--concurrency int 4 并发槽位数；min=1
--until-empty bool False 队列空了就退出
--max-minutes float \| None None 最多跑多少分钟
--no-reaper bool False 不启动卡住任务的回收器

jobs retry¶

将匹配状态任务重新入队。

副作用： 写队列，不能随意恢复历史成功任务或claim。

返回内容： kind/status/requeued。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--kind str \| None None 只看某个 kind
--status str JobStatus.FAILED.value failed | partial | done

jobs list¶

查看逐条任务。

副作用： 读数据库；默认limit=50。

返回内容： jobs列表，含id/kind/target_key/status/attempts/run_after/last_source/last_error。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--kind str \| None None 只看某个 kind
--status str \| None None 只看某个状态
--limit int 50 min=1, max=1000

tokens sync¶

同步全部有UCID的代币、合约与元数据。

副作用： 来源网络/免费额度/业务写入；小范围、刷新和补全均需确认。

返回内容： sync统计与stats；缺详情可返回4。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--limit int \| None None 最多取多少个 UCID（冒烟测试用，按 UCID 升序）；默认取 CMC 全部；min=1
--with-coingecko bool False 用 CoinGecko 补全缺失的合约（FR-04）
--skip-info bool False 只更新 UCID 列表，不取合约/tags/links（省 CMC credits）
--refresh-info bool False 强制重取全部详情（默认只取还没取过的，所以中途失败重跑会接着来）

tokens show¶

按UCID读已有代币、合约、标签/链接与部署结果。

副作用： 读数据库，不自动采集。

返回内容： 代币详情字典；不存在返回非成功及说明。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
ucid int 必填 CMC UCID

tokens resolve¶

按链和合约反查UCID，可选手动登记。

副作用： 先读本地，未命中可联网/记额；--add在非本地来源时写手动合约。

返回内容： chain/address/ucid/source/stored；无UCID返回4。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
chain str 必填 链，例如 ethereum、bsc、solana
contract str 必填 合约地址（EVM 不区分大小写）
--add bool False 查不到本地记录时，把它作为手动合约入库（FR-06）

tokens conflicts¶

查看UCID与同地址合约的冲突。

副作用： 读数据库；可包含已解决项。

返回内容： conflicts列表。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--all bool False 连已处理的也列出来

副作用： 读数据库，不刷新CMC集合。

返回内容： 总体与各链统计或表格。

labels import¶

导入完整验证的本地CSV或CMC交易所钱包标签。

副作用： 写标签；cmc_exchange还联网/记额，本地来源需path。

返回内容： source/imported；测试Fixture例为1，不代表正式库数量。

使用指南 · 实现源码

参数/选项 类型 默认 源码帮助/约束
--source str 必填 etherscan_dump | spellbook | file | cmc_exchange
--path Path \| None None exists=True, dir_okay=False
--snapshot-date str \| None None YYYY-MM-DD

返回内容： node_id/label_type/source；不代表自动证据或人工黄金验收。

副作用： 读数据库，不联网。

返回内容： node_id/labels/effective/excluded/requires_confirmation，直接JSON。

使用指南 · 实现源码

依据已有计数生成待确认标签。

副作用： 默认写标签；只有显式--dry-run才不保存，不自动升级为人工事实。

返回内容： dry_run/requires_confirmation/labels，直接JSON。

副作用： 读数据库；未同时入榜的余额差保持未知。

返回内容： before/after及rows等差异字段，直接JSON，以源码为准。

after int 必填 —

holders show¶

副作用： 读数据库；不重新采集、不偷偷修正历史身份。

返回内容： ucid/snapshots，包含来源、status、taken_at与holders，直接JSON。

副作用： 删除业务历史，必须单独授权，不是只读查询。

返回内容： deleted_snapshots。
