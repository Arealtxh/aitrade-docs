Python 业务接口¶

下列为内部Python服务，不是HTTP端点或承诺稳定的外部SDK。类型与签名从源码提取；初始化须由调用方提供会话工厂/路由等依赖。

项目异常¶

异常继承和原职责说明直接来自core/errors.py；CLI转换规则见退出码。

异常 继承 源码说明
AitradeError Exception 所有自定义异常的基类。
ConfigError AitradeError 配置缺失或非法（CLI 退出码 1）。
DatabaseError AitradeError 数据库操作失败（CLI 退出码 3）。
RateLimited AitradeError 被数据源限速。不计入 attempts，按 retry_after 推迟重试。
QuotaExhausted AitradeError 日/月额度用完。推迟到下一个窗口，并让路由器暂时跳过这个数据源。
TransientError AitradeError 可重试的临时错误：网络错误、5xx、响应被截断。
NotFound AitradeError 数据源明确表示「没有这个对象」，例如地址不存在、交易查不到。
CreationNotFound NotFound 创建证据缺失的稳定分类；候选区块不是已确认的部署区块。
EvidenceError ConfigError 关键证据无法安全留存或重放；必须中止，不能降级为已核验结果。
CollectionStopped ConfigError 本地采集的STOP/硬预算/时限要求安全停止，不触发路由备源。
Unsupported AitradeError 数据源不支持该链或该能力，路由器会切到下一个候选。
DataIncomplete AitradeError 拿到了数据但不完整，任务状态记为 partial，不静默吞掉。
